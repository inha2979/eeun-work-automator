# Eeun Work Automator

반복적인 이벤트 운영 및 Excel 정리 업무를 자동화하는 Streamlit 기반 로컬 웹앱입니다.

## v1.1 핵심 개선
- 서로 다른 Excel 구조 대응: 시트 선택 + 실제 헤더 행 선택
- 전화번호 / Instagram ID / 개인정보 동의 / 유효응답 열 자동 후보 감지
- 필요 시 모든 열을 사용자가 직접 지정 가능
- Excel Cleaner에 `중복여부` 표시 기능 추가
- Event Lottery에서 예비 당첨자 화면 표시
- 각 필터 단계의 `제외 인원 / 잔여 인원` 표시
- 제외 대상과 제외 사유를 결과 Excel에 별도 저장
- 보고용 추첨 문장 자동 생성
- 당첨자+예비 당첨자 수가 최종 후보보다 많을 때 안내

## 주요 기능

### 1. Excel Cleaner
- 전화번호 형식 통일
- Instagram ID 정규화
- 공백 제거
- 빈 행 제거
- 중복 탐지/표시/제거
- 시트 및 헤더 행 선택
- 정리 결과 Excel 다운로드

### 2. Excel Matcher
- 두 Excel/CSV 파일을 공통 키로 매칭
- 당첨자 ID를 기준으로 이름, 전화번호, 댓글 등 가져오기
- 서로 다른 시트/헤더 구조 지원
- 매칭되지 않은 데이터 별도 확인

### 3. Event Lottery
- 참여자 ID 정규화
- 중복 참여자 제외
- 개인정보 동의자 필터
- 유효 응답/추첨 자격 필터
- 팔로워 목록 대조
- 과거 당첨자 제외
- 당첨자/예비 당첨자 랜덤 추첨
- Seed 및 추첨 시각 기록
- 제외 사유 기록
- 보고 문장 자동 생성

## 파일 구조가 달라도 사용할 수 있나요?
네. 업로드 후 다음을 직접 지정할 수 있습니다.

1. 사용할 Excel 시트
2. 실제 열 이름(헤더)이 있는 행
3. Instagram ID / 전화번호 / 개인정보 동의 / 유효응답 등에 해당하는 열

따라서 회사에서 받은 파일의 열 순서나 열 이름이 매번 달라도 대부분 대응할 수 있습니다.

예를 들어 실제 파일이 아래처럼 되어 있어도:

- 1행: 이벤트명
- 2행: 안내 문구
- 3행: 이름 / 연락처 / SNS 계정 / 개인정보 동의
- 4행부터 실제 데이터

`실제 열 이름이 있는 행 = 3`으로 선택한 후 각 열을 지정하면 됩니다.

## 새 자동화 기능을 계속 추가할 수 있나요?
가능합니다. 이 프로젝트는 하나의 업무 자동화 허브로 확장하는 것을 전제로 합니다.

추가하기 좋은 예시:
- 설문 중복/불성실 응답 자동 검수
- 이벤트 당첨 이력 DB
- 여러 Excel 파일/시트 자동 병합
- 특정 조건별 참여자 분류
- 카드뉴스/블로그 원고용 자료 정리
- 전화번호/이메일/계정 데이터 품질 검사
- 자유응답 키워드 분류
- 업무 보고 문장 자동 생성

새 기능을 만들면 Streamlit 사이드바에 새 메뉴를 추가하는 방식으로 확장할 수 있습니다.

## 팔로워 파일이 없는 경우
Instagram에 반복 로그인하여 팔로워 여부를 자동 크롤링하는 기능은 계정 제한 및 서비스 정책 문제 때문에 기본 기능으로 포함하지 않았습니다.

대신 Event Lottery 메뉴에서 `팔로우 수동검증용 목록`을 다운로드할 수 있습니다.

1. 중복 제거된 Instagram ID 목록 다운로드
2. 팔로우 여부를 O/X 등으로 확인
3. 참여자 원본에 확인 결과 열을 추가
4. Event Lottery의 추첨 자격/검증 열 기능으로 O만 포함해 추첨

Meta에서 공식적으로 제공하는 계정 데이터 내보내기 파일을 확보할 수 있다면 해당 팔로워 목록 파일을 직접 업로드하여 자동 대조할 수 있습니다.
